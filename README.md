# Silene_Color
Silene acaulis petal color variation in western North America

Data - excel files with raw data
- Color_2024: location data for images taken in the field in the summer 2024
- Color_2025: location data for images taken in the field in the summer 2025

Scripts - scripts with code for color analysis
- Udell_Scripts: Python scripts for Udell et al. 2021 pipeline extracting average color from images without a color standard
- Kj_Scripts: Python scripts for extracting color data with a color standard
